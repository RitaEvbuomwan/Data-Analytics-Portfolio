## Project 2: Clinical Governance & Patient Safety Dashboard

A two-page Power BI dashboard analysing clinical governance and patient safety incident data across NHS organisations, regions and trust types.

### Dashboard Overview

![Clinical Governance Dashboard Overview](Clinical%20Governance%20Dashboard%20Overview.png)

### Detailed Analysis

![Clinical Governance Detailed Analysis](Clinical%20Governance%20Detailed%20Analysis.png)

### Key Metrics
- Total Incidents: 753K
- Total Organisations: 205
- Severe & Fatal Incidents: 7,168
- No/Low Harm: 86.76%
- Incident recording rates analysed per 1,000 bed days

### Dashboard Features
- Executive KPI cards
- Incident analysis by harm severity
- Incident analysis by NHS region
- Top 10 organisations by total incidents
- Top 10 organisations by severe & fatal incidents
- Organisation-level detailed analysis
- Interactive Region, Trust Type and Harm Severity slicers
- Cross-filtering across dashboard visuals
- Conditional formatting to highlight severe and fatal incidents
- Data bars for Total Incidents
- Page navigation between Overview and Detailed Analysis

### Tools & Skills
- Power BI Desktop
- Power Query
- DAX Measures
- Data Modelling & Relationships
- Data Cleaning & Transformation
- KPI Development
- Interactive Data Visualisation
- Conditional Formatting
- Top N Analysis
- Healthcare / Clinical Governance Data Analysis
